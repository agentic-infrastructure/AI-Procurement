# artifacts/archive/

Superseded versions and retired artifacts.

- Mirror the live structure: `artifacts/archive/[artifact-name]/` (and `[sub-artifact-name]/` when used).
- Move the prior version here whenever a new `_v##` is saved in `artifacts/[artifact-name]/`.
- Retired artifacts move here, folder and all, with status `retired` in `artifacts/ARTIFACTS.md`.
- Do not delete files here; they explain past outputs and decisions.
