# OBJECTIVES.md — Project Objectives

## File Guidance
Defines what this project is trying to achieve. **AI reviews this file every run** and uses it to prioritize work and resolve trade-offs. **Maximum of 5 objectives.**

## Objectives
The objectives of this project are to:
1. Establish an efficient, overarching procurement policy with standards, templates, descriptions, process maps, vendor landscapes, and vendor communications tracking.
2. Provide standard RFx packages and process templates.
3. Produce consistent, normalized bid comparisons that track over time, across all RFx activities for a specific scope.
4. Maintain an approved vendor list (AVL) with qualification records.
5. Define the PO process.

## Success Measures (optional)
| Objective | How success is measured |
|---|---|
| All | The Procurement Lead can efficiently manage the work as a single person, with the help of AI. |

## Rules
- AI does not add, remove, or reword objectives; it may propose changes for user approval (log in `prompts/DECISIONS.md`).
- When work does not serve an objective, AI flags it before investing significant effort.
